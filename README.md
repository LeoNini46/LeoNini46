## 📂 Featured Engineering Projects

### 📊 [Formula 1 Telemetry & Vehicle Dynamics Analysis](https://github.com/LeoNini46/f1-telemetry-vehicle-dynamics)
**Tools:** `MATLAB` `Mathematica`
Processing and manipulation of raw telemetry data from a 2013 Formula 1 car at the Barcelona Circuit. The project focuses on data filtering, trajectory reconstruction of the vehicle's center of mass via single-track vehicle models, aerodynamic/lateral load evaluation, and grip limit analysis (Grip-Limited vs. Power-Limited boundary conditions).

### 🏍️ [MIMO Dynamic Systems & Traction Control Modeling](https://github.com/LeoNini46/mimo-vehicle-traction-control)
**Tools:** `MATLAB` `Simulink`
Development of a non-linear 1D MIMO dynamic model for a high-performance motorcycle (Ducati Panigale V2) to implement roll and yaw stability control. The project includes state-space system linearization, stability assessment via Lyapunov's indirect method, pole-placement observer-regulator architecture design, and Region of Asymptotic Stability (RAS) estimation.

### 🔧 [Pit Stop](https://github.com/LeoNini46/PIT-STOP)
**Tools:** `Supabase` `Vercel`
Web app to manage a racing team garage or a personal vehicle: maintenance schedules by km/hours, document expiry tracking (insurance, inspection), cost overview and tyre set archive.
